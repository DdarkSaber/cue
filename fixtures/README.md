# Fixtures

Synthetic, sanitised sample files only, for import adapter tests (M4 onward).

- Never copy a real export (MAL, Netflix, Mihon, Cue backup) here, even trimmed.
- Invent titles or use well-known public titles with made-up dates, scores and progress.
- `.gitignore` blocks the usual real-export filenames; name fixtures
  `synthetic-<source>-<case>.<ext>` so they don't collide with those patterns.
